# 宿泊税クラウド（デモ）

民泊・簡易宿所の運営代行会社向けに、宿泊税の「判定 → 確認 → 明細 → 申告準備」を一つの画面でまとめるサービスの画面イメージです。

- 公開URL: https://www.vitality-design.jp/demo/hotel-tax
- 本体: `demo/hotel-tax/index.html`（HTML 1ファイル。外部ライブラリなし、Google Fonts のみ読み込み）
- データ・物件・オーナーはすべて架空です。税率と区分はデモ用の値で、実際の条例とは異なります。
- 検索エンジン・AIクローラーには載せない設定です（`<meta name="robots">` と `vercel.json` の `X-Robots-Tag`）。

## 想定する使い方

| 役割 | 画面上の呼び方 | やること |
| --- | --- | --- |
| 運営代行会社 | 貴社 | 要確認の確認・確定、オーナー明細の送付、自社名義分の申告 |
| 物件オーナー | オーナー様 | 明細を受け取る。計算は不要。最終確認は特別徴収義務者として行う |
| 本サービス | 当社 | 予約データの取り込みと1泊ごとの判定、集計 |

申告・納入は特別徴収義務者（オーナー様または貴社）の名義で行います。本サービスは集計と申告準備の支援で、税務代理は行いません。

## 月の流れ

ホーム画面に、今月どこまで進んだかを5つのステップで表示します。

1. **取込**: Beds24（API／CSV）と手間いらず（CSV）から前月分の予約を取り込む
2. **判定**: 予約を1泊ごとに分け、自治体のルールで税額を決める
3. **要確認**: 自動で決められない予約だけを確認・修正して確定する
4. **確定・明細送付**: 要確認が0件になったら今月分を確定し、オーナー明細を代行明細書（毎月20日ごろ）に添付する
5. **申告**: 申告名義 × 自治体ごとの集計表を出す（期限は翌月末）

期限の7日前・3日前・前日に、担当者とオーナーへメールで知らせる想定です。

## 画面

| ホーム | `#home` | 5ステップ（取り込み前は「CSVを取り込む」から）、本来預かるべき宿泊税（確定分）、要確認件数、期限までの日数 |

| 設定 | `#setup` | 物件（申告名義、チャネルごとの税込み／別途）、自治体のルール、清掃料の扱い、データの取り込み |

## 判定のルール

### 1泊ごとに判定する
1人1泊の金額 =（1泊の料金 + 清掃料の割り当て）÷ 人数。この金額で泊ごとに区分を決め、合計します。予約全体の平均では判定しません。

### 1泊の料金の出どころ
- **予約データ**: 1泊ごとの料金がデータにある
- **料金カレンダーで補完**: Beds24 の Airbnb 予約など合計金額しかない場合、料金カレンダーの料金で分ける
- **合計と合わない**: カレンダーの合計が予約の合計と一致しない → 要確認

### 税込み（みなし）と別途徴収
物件ごと・チャネルごとに「税込み」「別途徴収」「未設定」を持ちます。税込みの場合は料金から税額を引いてから区分を決めます。引く税額によって区分が変わる金額帯（例：大阪府 税込み1人1泊 15,200〜15,399円）は自動で決めず、要確認にします。

### 清掃料の扱い（大阪府）
「泊数で按分」と「初泊に計上」を設定で切り替えます。府税事務所に確認中のため、画面にもその旨を表示しています。

### 要確認になる理由
| 理由 | 確認の内容 |
| --- | --- |
| 料金の合計が合わない | 合計を按分する／カレンダーの料金を使う／手入力 |
| 区分の境目の金額 | どちらの税額にするか選ぶ |
| 清掃料かどうか不明な料金 | 手間いらずの「追加料金」を宿泊料金に含めるか |
| 税込みか別途か未設定 | そのチャネルの設定を決める（同じチャネルの全予約に反映） |

**集計に入るのは確定した予約だけです**（自動で確定したもの＋確認して確定したもの）。

### 取りもれの表し方
主に出す数字は「本来預かるべき宿泊税」です。「預かった額との差」は、預かった額がデータで確認できた予約（宿泊税の明細行がある、または税込みの額が物件設定にある）だけで計算し、件数とあわせて表示します。確認できない予約について差は出しません。

### 取り込まない項目
ゲストの氏名・連絡先は取り込みません。

## デモデータ

固定の乱数（シード値 `20261021`）で毎回同じデータを作ります。対象月は「表示した日の前月」です。

- 物件 144（大阪府 80、京都市 18、東京都 16、福岡市 8、札幌市 6、沖縄県 6、金沢市 4、倶知安町 3、長崎市 3）
- オーナー 46（法人・個人・海外オーナー）
- 予約 約920件、うち要確認 約55件
- 申告 約90件（申告名義 × 自治体）
- 取込元: Beds24 約75%、手間いらず 約25%

自治体のルール（デモ値）は `index.html` 内の `RULES` にあります。区分制（`tier`）と料金の割合（`pct`、沖縄県は上限あり）の2種類です。

## デモの流れ（CSV取り込みから申告まで）

最初は「取り込み前」の状態から始まり、次の順に一通り体験できます。各画面の上に、次にやることのボタンが出ます。

1. ホームの「CSVを取り込む」→ Beds24・手間いらずのCSVを選ぶ（ドロップ／ファイル選択／「サンプルを使う」）→「取り込む」
2. 判定の進み具合が表示され、終わると件数（自動で確定・要確認）が出る →「要確認の確認へ」
3. 要確認を「確定して次へ」で処理（残りは「残りをおすすめの内容で確定」でまとめて可）→「今月分を確定」
4. オーナー明細で「明細を送付（46名）」→ 送付の確認 →「申告の準備へ」
5. 申告で「申告用の集計表を出力」→ ホームが全ステップ ✓ になる

- 取り込み前は、要確認・予約・オーナー明細・申告の画面に「CSVを取り込む」案内だけを出します（設定の物件一覧は見られます）。
- CSVは1行目の列名で Beds24（`bookId`）か手間いらず（`予約番号`）かを見分けます。どちらでもないファイルはエラーにします。UTF-8 と Shift_JIS に対応。
- 取り込み画面の「サンプルCSVをダウンロード」で実際のCSVファイルを保存できます。それをドロップすれば、ファイルを使った取り込みを見せられます。
- 取り込み後に表示するのは、いつも同じデモデータです（選んだCSVの中身は件数の表示にだけ使います）。

## デモの操作について

- 確定などの操作は、見ている人のブラウザに保存されます（`localStorage` の `stax3-state`）。ほかの人には共有されません。
- 打ち合わせの前に、ページ下の「デモを最初の状態に戻す」で初期状態に戻してください。
- 要確認の一覧の下にある「残りをおすすめの内容で確定」で、残りをまとめて確定できます（デモ用）。
- CSV は画面に中身を表示してコピーする形、PDF はメッセージ表示のみです（実際のファイルは作りません）。
