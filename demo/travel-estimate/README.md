# 旅行見積システム（デモ）

旅行会社の見積作成業務を対象にした操作モックです。ヒアリングで「この操作の方向性でよいか」を確かめるために使います。

- 公開URL: https://www.vitality-design.jp/demo/travel-estimate
- 本体: `demo/travel-estimate/index.html`（HTML 1ファイル）
- 案件・顧客・料金はすべて架空です。税・手数料・部屋割りは計算していません
- 作らないもの: AIによる処理、外部の料金検索、保存・ログイン、ファイル出力

## 画面と流れ

**案件一覧 → 要望・条件 → 明細・積算 → 見積書プレビュー**

| 画面 | URL | できること |
| --- | --- | --- |
| 案件一覧 | `#list` | 新規見積、編集、複製、案件名・顧客名での検索 |
| 要望・条件 | `#request` | 依頼メールと条件の入力、「デモ案件を読み込む」、入力チェック |
| 明細・積算 | `#items` | 行の追加・複製・削除、単価・数量・回数の編集、即時の再計算、要確認／確認済の切り替え、人数変更、元に戻す |
| 見積書プレビュー | `#preview` | 顧客向けの内容だけを表示。PDF／Excel／指定書式は「未実装」と表示 |

画面を移動しても入力した値は消えません（ページを再読み込みすると最初の状態に戻ります）。

## 計算

- 原価小計 = 原価単価 × 数量 × 回数、販売小計 = 販売単価 × 数量 × 回数
- 粗利額 = 販売合計 − 原価合計、粗利率 = 粗利額 ÷ 販売合計 × 100（小数第2位まで。販売合計が0のときは「—」）
- 金額・数量・回数は0以上の整数のみ。負数・文字・空欄の行はエラー表示にして合計に含めません

デモ案件（DEMO-001・20名）の初期値: 原価 1,090,000円／販売 1,340,000円／粗利 250,000円（18.66%）。
18名に変えると、人数連動の3行だけ数量が18になり、原価 1,007,000円／販売 1,238,000円になります。

## モック内で決めた暫定の動き

仕様書に書かれていない部分は、次のように決めています。実際の業務ルールではありません。

- 依頼文から条件を自動で読み取ることはしません。「デモ案件を読み込む」は固定値を入れるだけで、画面にもそう表示します
- 「見積項目を作成」は、どの案件でもデモ用の固定明細5行を読み込みます。人数連動の行の数量は入力した人数にそろえます
- 日程を変えると、新幹線・ホテル・ガイド・貸切バスを要確認にします。宿泊希望を変えるとホテルを要確認にします
- 状態は、見積書を開くと「プレビュー済」、その後に編集すると「作成中」に戻ります
- 明細の「備考（社内）」は社内メモとして扱い、見積書には出しません
- 見積書の「見積条件」はサンプル文言です
- 要望・条件の画面では、顧客名・案件名・出発日・帰着日・人数を必須にしています

## 受け入れテスト

仕様書の T1〜T10 は、画面と同じ関数を使って確認済みです（すべて合格）。
