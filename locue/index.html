HOW IT WORKS

入口はシンプルに。
出口は課題に合わせて。

LOCUEは「一次情報を取得する入力インターフェース」と「価値に変えて届ける出力インターフェース」の2つで構成。AIエンジンはその間で情報を変換します。

01 / INPUT INTERFACE
📷
撮る・話す・伝える写真 / 動画 / 音声 / QR

入力インターフェース

現場の一次情報を、誰でも最小限の操作で提供できる入口。従業員だけでなく、宿泊者・利用者・協力業者も必要に応じて参加できます。

01 / REPAIR

不具合・修繕管理

現場報告、優先度の整理、担当者連携、チャット・添付、修繕費用と履歴を一元化。必要な確認だけを人に返す。

02 / INSPECTION

点検・年間計画

日常・定期・法定点検の項目、頻度、担当者、期限、記録、承認、年間予定を管理。HACCPなど用途別の記録も視野に。

03 / VENDOR

外注手配・日程調整

設備情報や写真をまとめて共有。業者は専用URLから訪問可能日を回答し、ホテル側の条件と照合して手配を支援。

04 / ASSETS

設備・施設台帳

施設、フロア、客室、設備を紐づけ、過去の修繕や点検結果を検索。既存CSV等からの移行も検討。

05 / INVENTORY

備品・在庫管理

消耗品の数量や保管場所、不足通知、発注判断を支援。共通の現場入力インターフェースから利用する構想。

06 / INSIGHTS

レポート・多拠点管理

修繕件数、対応時間、費用、点検実施状況を見える化。施設ごとの権限を守りながら本部で横断確認する。

FAQ

よくあるご質問

LOCUEは現在利用できますか？

現在はサービス構想・顧客検証段階です。実際の現場課題を伺いながら、共同実証パートナーを募集しています。完成済みの提供機能としてご案内しているものではありません。

現場のスタッフや協力業者にも費用がかかりますか？

現場の情報入力者には原則無料で利用いただく構想です。費用は、課題解決にLOCUEを活用する企業・施設からいただくB2Bモデルを想定しています。

設備管理以外の業務にも使えますか？

Maintenanceに加え、Quality・Experienceを展開する構想です。現場の入力・AI変換を共通基盤として、用途ごとに必要な業務実行フローを整備していきます。

既存の管理システムと連携できますか？

CSV等によるデータ移行や、既存システムとの連携を想定しています。対応範囲は今後の検証・開発で決定します。
