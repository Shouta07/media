# 資料づくりのプロンプト集

AI（Claude など）に資料をつくらせるときのプロンプトです。
`{ }` の所を埋めて、そのまま貼って使います。

**いきなり完成品を頼まないでください。** 次の4段階に分けると、やり直しが少なくなります。

```
STEP 0 前提を渡す   → STEP 1 構成案   → STEP 2 ページ原稿   → STEP 3 HTML化   → STEP 4 セルフチェック
（毎回の最初に）       （見出しだけ）       （文字だけ）          （ひな形に流す）      （ルールと照合）
```

各段階で人が確認してから次へ進みます。直すなら、文字だけの段階（STEP 1・2）で直すのがいちばん安く済みます。

---

## STEP 0　前提（会話の最初に毎回貼る）

Claude Code でこのリポジトリを開いているなら、ファイル名を渡すだけで足ります。

```
これから Vitality Design の資料をつくります。
作業の前に、次のファイルを読んでルールとして守ってください。

- slides/FORMAT.md        … 資料のフォーマット（最優先）
- README.md の 8節        … 書いてよいこと・いけないこと
- llms.txt                … 会社情報
- slides/deck-16x9.html, slides/paper-a4.html … HTML のひな形

特に守ってほしいこと：
- 見出しは結論の1文にする（ラベルにしない）
- 1ページに言いたいことは1つ、本文の部品は1つ
- 実績・顧客名・成果を、事実として言えないのに書かない
- 「AIっぽい」見た目と言葉（FORMAT.md 7節）を使わない

読み終わったら、守るルールを5行で要約してから、私の次の指示を待ってください。
```

リポジトリを開いていない場合（ブラウザの Claude など）は、`FORMAT.md` の全文を貼り付けて
「以下のフォーマットに従ってください」と添えます。

## STEP 1　構成案（見出しだけ）

`outline-template.md` を埋めてから使います。

```
次の条件で資料の構成案をつくってください。まだ本文は書かないでください。

- 資料の種類：{サービス紹介資料 / 調査レポート / 商談用スライド / デモ説明 / 社内向け}
- 判型：{16:9 スライド / A4縦}
- 読む人：{例：民泊運営代行会社の代表。宿泊税の申告を毎月手作業でしている}
- 読んだあとに決めてほしいこと：{例：15分のデモの打ち合わせを入れる}
- 使える事実・材料：
  {箇条書きで。ヒアリングのメモ、件数、デモのURL、価格の考え方など}
- 言えないこと：{例：導入実績はまだない／効果は実証していない}

出してほしいもの：
1. 表（ページ番号 / ページの型 / 見出し（結論の1文） / そのページの根拠になる材料）
2. 見出しだけを上から順に読んだときの文章（話がつながるかの確認用）
3. 材料が足りず、私に確認が必要な点

ページの型は FORMAT.md 4節のものだけを使い、枚数は目安の範囲に収めてください。
```

**確認すること**：見出しだけ読んで話がつながるか。最後のページに「決めてほしいこと」が1つあるか。

---

## STEP 2　ページ原稿（文字だけ）

```
構成案のとおりに、各ページの原稿を書いてください。まだ HTML にしないでください。

ページごとに次の形で：
---
[p.{番号}] 型：{表 / 流れ / 数字 / …}
ラベル：{章番号 ／ 章名}
見出し：
リード：（2文まで。太字にする所を **〜** で示す）
本文：（表なら Markdown の表、流れならステップの箇条書き）
補足：（1段落まで。なければ「なし」）
注記：（必要な場合だけ）
---

守ること：
- です・ます調、1文40字まで
- {読む人} が毎日使う言葉で書く。「実現」「シームレス」「最適化」などは使わない
- 数字には単位と条件を付ける。材料にない数字はつくらない（必要なら「要確認」と書く）
- 表は4列×5行まで
```

**確認すること**：材料にない数字や事実が混ざっていないか。相手の呼び方が統一されているか。

---

## STEP 3　HTML 化

```
確定した原稿を、slides/{deck-16x9.html / paper-a4.html} をもとに HTML にしてください。

- ひな形をコピーして {保存先：例 ~/Documents/資料/2026-12-hotel-tax.html} に保存する
  （お客様名や商談の中身が入る資料は、このリポジトリには保存しない）
- ひな形にあるページの型（.s-cover / .s-table など）だけを使い、新しい部品をつくらない
- アクセント色は --accent / --accent-on-dark を {色の名前 or 値} に変える。ほかの色は変えない
- 色・サイズを直接書かない。変数とひな形のクラスを使う
- 使わない型のページは削除する

できたら、ブラウザで開いて確認する手順と、PDF にする手順を書いてください。
```

---

## STEP 4　セルフチェック

```
できた資料を、slides/FORMAT.md の 10節のチェックリストで1項目ずつ確認してください。

- 各項目を「OK / NG」で答え、NG は該当ページと直し方を書く
- 特に README.md 8節（実績・成果・製品の書き方）に反する文がないか、全文を確認する
- 見出しだけを上から並べて出す
- 直してよいと言うまで、ファイルは変更しない
```

## 部分的に使うプロンプト

### 見出しを結論の1文に直す

```
次の見出しを、そのページで言いたい結論の1文に書き直してください。
各見出しにつき3案。20字前後、です・ます調で、ページの本文から言えることだけを使ってください。

{見出しとそのページの本文}
```

### 「AIっぽさ」を抜く

```
次の文章から、AIが書いたように見える表現を抜いて書き直してください。

- 抽象語（実現、最適化、シームレス、次世代、価値提供、ソリューション）を具体的な動作に置き換える
- 「〜することで、〜を可能にします」の形をやめ、主語と動詞を短く
- 3つ並べるのが目的になっている列挙を、本当に必要な数に減らす
- 相手の現場の言葉（{例：清掃料、代行明細、府税事務所}）を使う

{文章}
```

### 表に整理する

```
次のメモを、FORMAT.md の「表」の型（4列×5行まで）に整理してください。
1列目は相手の場面（いつ・どこで）、最後の列は「こちらがすること」にしてください。
表の上に結論の見出し1文とリード1〜2文、表の下に補足1段落を付けてください。

{メモ}
```

### 言いすぎを点検する

```
次の資料の文から、事実として言えないのに言い切っている所を探してください。

- 実績・顧客数・導入企業・お客様の声に見える所
- 効果（売上、稼働率、成約率、時間削減など）を保証しているように読める所
- 構想段階のものを、提供中の製品のように書いている所
- 調査の数字で、件数・方法が添えられていない所

それぞれ、該当の文と、言える範囲に直した文を並べてください。

{資料の本文}
```

### 調査メモからレポートをつくる（89件レポート型）

```
次の {件数} 件の{面談 / ヒアリング}のメモから、調査レポート（A4縦・4〜6ページ）の構成案をつくってください。

- 表紙のコピーは、比べると分かる対の2行にする（例：「決まる面談と、/ 決まらない面談。」）
- 副題に、対象・件数・方法を書く（例：「人材紹介会社の候補者面談89件を1件ずつ聞いて、分かったこと。」）
- 「分かったこと」は3つまで。それぞれ、何件中何件で見られたかを添える
- メモにない傾向や数字はつくらない。件数が少なく言い切れないものは「傾向」と書く
- 個人や会社が特定できる情報は入れない

{メモ}
```

### デモの説明スライドをつくる

```
demo/{名前}/README.md と demo/{名前}/index.html を読んで、
商談でデモを見せる前に映す説明スライド（16:9・5枚まで）をつくってください。

- 1枚目：表紙（相手の業務名と「画面イメージ」の表記）
- 2枚目：相手の月の流れ（流れの型）。README の「月の流れ」をそのまま使う
- 3〜4枚目：画面（画面の型）。デモの画面のうち、相手が一番困っている所を2つ
- 5枚目：次の一歩と「画面イメージです。データはすべて架空です。」の注記
- デモにない機能は書かない
```

## うまくいかないとき

| 症状 | 直し方 |
| --- | --- |
| 見出しがラベル（「課題」「概要」）になる | STEP 2 の前に「見出しを結論の1文に直す」を挟む |
| 1ページに詰め込みすぎる | 「このページで言いたいことを1文で言って。それ以外は別ページか削除」と頼む |
| 数字を勝手につくる | 「材料にない数字は書かず『要確認』と書く」を毎回入れる |
| 見た目が派手になる（影・グラデ・アイコン） | 「ひな形のクラスだけを使い、CSS を足さない」と入れる |
| 自社紹介から始まる | 「自社紹介は最後のページだけ」と入れる |
