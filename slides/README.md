# スライド・資料づくりキット

Vitality Design の資料（サービス紹介、調査レポート、提案書、デモ説明など）を
同じ型でつくるためのフォーマットとプロンプト集です。

これまでの実装からルールを抜き出してまとめています。

| 元にしたもの | 取り入れたこと |
| --- | --- |
| `docs/doc-*.png`（FIELD CX サービス紹介資料） | A4縦の型、`02 ／ 設計対象` のページ見出し、結論を1文で書く見出し、表を中心にした本文 |
| `docs/vd-89-*`（候補者面談89件のレポート） | 暗い表紙にアクセント1色、件数と方法を書いた副題 |
| `demo/DESIGN.md` | 情報量の上限、「AIっぽく」見えるもの、相手の現場の言葉で書くこと、架空データの決まり |
| `README.md` §8 | 実績・成果・製品について書いてよいこと、いけないこと |
| `assets/site.css` / `llms.txt` | 会社の色・書体・会社情報 |

---

## フォルダ

```
slides/
├─ README.md               このファイル
├─ FORMAT.md               フォーマット（判型・ページの型・色・文字・書き方・チェックリスト）
├─ PROMPTS.md              AI に資料をつくらせるときのプロンプト集
├─ outline-template.md     つくる前に埋める構成シート
├─ deck-16x9.html          スライド（16:9）のHTMLひな形。ページの型をすべて収録
└─ paper-a4.html           A4縦の資料のHTMLひな形（FIELD CX と同じ型）
```

---

## 使い方

1. **`outline-template.md` を埋める**
   誰に、何を決めてもらう資料かを先に決めます。ここが空のまま作り始めないでください。
2. **判型を選ぶ**
   画面に映す・オンライン商談で見せる → `deck-16x9.html`
   メールで送る・印刷して渡す・読み物として渡す → `paper-a4.html`
3. **`PROMPTS.md` の手順で AI に作らせる**
   構成案 → ページごとの原稿 → HTML 化 → セルフチェック、の順です。いきなり HTML を書かせないでください。
4. **ブラウザで開いて確認し、PDF にする**
   Chrome で開き、印刷 → 「PDFに保存」。余白「なし」、「背景のグラフィック」にチェック。
5. **`FORMAT.md` 末尾のチェックリストを通す**

ひな形は HTML 1ファイルで完結し、外部の読み込みは Google Fonts だけです。

```bash
python3 -m http.server 8237
open http://localhost:8237/slides/deck-16x9.html
```

## 置き場所の注意

このリポジトリは Vercel でそのまま公開されます。`slides/` 以下のファイルも URL で開けます。

- ひな形・ルールはここに置いてかまいません
- **お客様名や商談の中身が入った完成資料は、このリポジトリにコミットしないでください**
  （社内のドライブなどに置きます）
- 公開してよい資料（例：`docs/vd-89-interviews.pdf`）だけ `docs/` に置きます
- ルールやひな形を直すときも、**お客様名・担当者名・商談の数字を、ファイル・コミットメッセージ・PR の本文に書かないでください**。
  見本にした資料は「宿泊税クラウドのご紹介資料（2026年11月）」のように、相手が分からない形で書きます
  （詳しくはリポジトリ直下の `README.md` 8節「公開リポジトリに載せないもの」）
